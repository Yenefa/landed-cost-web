# 落地价 · Africa Landed Cost Calculator

一个给「想去非洲卖货」的中国卖家算真实账的工具。输入产品、数量、渠道，输出**单件落地成本、建议售价、单件净利、回本率、现金流周期**，并把成本拆到每一项（关税/增值税/认证/清关/佣金/退货）。

> 目的不是告诉你「非洲能暴富」，而是把暴富幻想换算成一张能看懂的账。算完还觉得能干，再干。

当前版本：**v0.4.0 · 尼日利亚 / 肯尼亚 / 南非（三国对比）**

线上地址：<https://yenefa.github.io/landed-cost-web/>

> 界面结构参考了 Jumia 官方「海外仓产品定价计算器」的做法（编号步骤卡片 + 单一强调色 + 大结果区），并在此基础上加强了成本拆分、回本率、敏感性与风险提示的可读性，以及**同一批货在三个市场的一屏对比**。参考站点：<https://www.jumia-global.com.cn/static/JumiaPrice.html>

## 快速开始

双击 `index.html` 即可（纯静态，无需构建、无需联网）。

或者起个本地服务：

```powershell
py -m http.server 8000
# 打开 http://127.0.0.1:8000/project-041-africa-import-calculator/
```

```powershell

```

## 它能算什么

- **尼日利亚进口税费**：关税（ECOWAS CET 按品类）、7% 附加费、1% CISS、0.5% ETLS、7.5% VAT（对 CIF+税费计征，公式与来源见下）
- **头程运费**：海运拼箱（USD/CBM）× 体积，或空运（USD/kg）× 重量
- **强制认证**：按品类自动识别 SONCAP / NAFDAC，并计入成本
- **Jumia 费用**：类目佣金（5%–20%）、回款手续费、对费用征的 7.5% VAT
- **单件经济**：平台费、广告、退货成本、单件净利与净利率
- **整批经济**：整批成本、回本销量、回本率、整批盈亏（₦ 与 ¥）
- **现金流**：生产 + 头程 + 清关 + 周转 + 回款的周期天数，与最大资金占用
- **敏感性**：奈拉升/贬值 ±15% × 退货率三档，直接看净利怎么变
- **风险提示**：净利过薄、退货率过高、高税品类、缺认证、回本不了、现金周期过长等自动预警

## 它不算什么（边界）

- **不是报价**：运费、认证费、清关费是参考值，真实以货代/报关行/认证机构报价为准，页面可直接改。
- **不是税务/法律意见**：税率与征管口径以 NCS（尼日利亚海关）与官方公告为准。
- **不含特殊监管**：药品、食品、车辆、二手设备等有单独准入与许可，本工具只做通用商品估算。
- **汇率是变量不是常量**：默认 NGN/USD=1500、CNY/USD=7.1 为参考值，请按当天实际情况改。

## 代码结构

```
project-041-africa-import-calculator/
├── index.html            # 页面骨架
├── assets/style.css      # 深色主题
├── src/
│   ├── data.js           # 国家 / 渠道 / 运费参数（配置化，加国家只改这里）
│   ├── calc.js           # 计算内核（纯函数，Node 可测）
│   └── app.js            # DOM 绑定与渲染
├── tests/calc.test.js    # 20 项断言
└── README.md
```

**分层原则**：数字全部由 `calc.js` 用确定性代码算，界面只负责展示。以后接 LLM 做「解释/建议」时，模型不许碰数字。

## 加一个国家（例：肯尼亚）

1. 在 `src/data.js` 的 `countries` 里加 `KE`：关税（EAC CET）、VAT 16%、IDF 2.5%、RDL 2%、PVoC 认证。
2. 在 `channels` 里加 `kilimall`：佣金表、回款周期。
3. 在 `freight` 里加中国→蒙巴萨的运价。
4. 顶部加一个市场切换器（v0.2 做）。

架构已经是「国家 × 渠道 × 运费」三维配置，不需要动 `calc.js`。

- 免费：算 1 个 SKU、看单件成本
- 付费：多国对比、批量 SKU、PDF 报告、汇率预警
