# MASTER · 落地价（非洲落地成本计算器）

> 由实际 CSS（`assets/style.css`）与 `ui-ux-pro-max` 设计知识整理，经 design-critic R1→R2 修复后定稿。
> 页面级规则以此为准；改设计先改本文件与 Token。

## 0. 产品与气质

- 定位：给中国跨境卖家算非洲落地成本的单页工具。
- 用户：准备做 / 正在做非洲电商的中小卖家与贸易商。
- 核心任务：**60 秒内判断"这批货还能不能做"**。
- 气质：可信（数字严谨）、克制（纸感留白）、有编辑感（大标题 + 小票式结果卡）。

## 1. 色彩（R2 实测对比度）

| Token                 | 值                    | 用途                              | 对底色对比度     |
| --------------------- | --------------------- | --------------------------------- | ---------------- |
| `--paper`             | `#F5F1E8`             | 页面底                            | —                |
| `--surface`           | `#FFFFFF`             | 卡片                              | —                |
| `--ink`               | `#111814`             | 主文字                            | ≈15:1（纸）      |

| `--muted`             | **`#5A615B`**         | 正文辅助                          | **≈5.5:1** ✔     |

| `--amber`             | `#E9A13B`             | 填充强调（按钮/色带）             | 非文字           |

## 2. 字体与字阶

- 字体：`Manrope`（拉丁）+ `PingFang SC / Microsoft YaHei`（中文）；数字 `IBM Plex Mono`。
- 字阶：11（眉标）/ 12（辅助）/ 13.5（导航）/ 15（正文小）/ 16.5（lede）/ 17–22（标题）/ 34–64（hero）。
- 行高：正文 1.55–1.7；hero 1.06。
- 数字：`font-family: var(--mono)`；金额列右对齐。

## 3. 间距与栅格

- 4/8 体系；卡片内 18–24px；区块间 16–24px。
- 内容最大宽 1240px。
- 断点：560 / 820 / 900 / 980。
- 移动端统计卡：`grid-template-columns:repeat(3,minmax(0,1fr))`。

## 4. 圆角 / 阴影 / 动效

- 圆角：输入 11、按钮 10、卡片 18、结果卡 22。
- 阴影：`0 1px 2px rgba(20,27,23,.04), 0 12px 30px -18px rgba(20,27,23,.25)`。
- 动效：`rise` 0.55–0.6s 入场；`prefers-reduced-motion` 下全部关闭。

## 5. 组件状态

| 组件     | default       | hover            | focus-visible           | disabled           |
| -------- | ------------- | ---------------- | ----------------------- | ------------------ |
| 输入框   | 边 `--line-2` | 边变深           | `--amber` 边 + 4px 光晕 | 无（当前只读展示） |
| 导航链接 | `--muted`     | `--ink` + 纸色底 | 2px `--amber-2` 外描边  | —                  |
| 重置按钮 | 边 `--line-2` | 边 `--ink`       | 同上                    | —                  |
| 结果卡   | 深墨底        | —                | —                       | —                  |

## 6. 无障碍约束

- 所有正文级文字 ≥4.5:1（R2 已验证 0 失败）。
- 交互元素 `:focus-visible` 统一 2px `--amber-2`。
- 导航/品牌/重置按钮命中区 ≥44px；行内文字链接按 WCAG 2.5.8 AA（≥24px）执行。
- `prefers-reduced-motion` 生效。

## 7. 禁止项

- 紫色渐变、玻璃拟态、无理由大圆角堆叠
- emoji 当结构图标（国旗为装饰例外）
- `outline:none` 无替代
- 亮琥珀 `#E9A13B` 作小字文字
- 组件内裸 hex（必须用 Token）
